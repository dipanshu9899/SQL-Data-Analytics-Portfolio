## 📁 Projects Index

### 1. 🚗 Uber Rides Operational & Financial Metrics Analysis
- **Description:** Analyzed a realistic transportation database to extract operational insights on ride statuses, driver performances, and financial metrics.
- **Skills Used:** SQL Data Definition (DDL/DML), Conditional filtering (`WHERE`), Aggregations (`SUM`, `COUNT`), Grouping (`GROUP BY`), and Result Limiting.
- **Key Insight:** Filtered out low-rated drivers for quality warnings and discovered that `UPI` is the dominant digital payment method driving transaction volumes.
